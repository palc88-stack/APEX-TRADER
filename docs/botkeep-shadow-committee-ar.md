# دمج مراقب اللجنة الكمية وسياسة التشغيل

## نطاق الدمج

أُعيد تنفيذ **فكرة** لجنة Baselbot كملخص Python داخل `bot/learning/committee_shadow.py`، ولم يُنقل محرك TypeScript حرفياً. يصف الملخص أصوات الفحوص الحتمية الموجودة في Shadow لدى APEX: الاتجاه، جودة الدخول، المشاركة/الحجم، الزخم، ونمط السكالبينغ عند انطباقه. الأصوات ليست نماذج مستقلة ولا احتمالات نجاح.

تُخزن النتيجة ضمن JSON `features` لجدول Shadow الموجود في Supabase. لا توجد هجرة schema مطلوبة. لا تملك اللجنة أي صلاحية لفتح/إغلاق أمر أو تغيير إشارة الاستراتيجية أو حجم الصفقة أو حدود المخاطر. إذا لم تتوفر قيمة Boolean موثوقة، يمتنع العضو عن التصويت. دمجها رصدي، ويظل `SHADOW_MODE` شرط التشغيل.

## توزيع المسؤوليات

- **Botkeep**: عامل Python 3.11 المستمر (`python -m bot.main`، و`APEX_RUN_CYCLES=0`)؛ إعداداته المفحوصة Testnet فقط، `ALLOW_LIVE_TRADING=false` و`SHADOW_MODE=true`. ثبت وجود قفل `apex-trading-execution` يجدد مالكه باستمرار.
- **GitHub Actions**: Workflows التي تسمح بالتنفيذ تصبح يدوية فقط كمسار احتياطي؛ لا جلسات تداول مجدولة تنافس Botkeep. يبقى الفحص اليومي المجدول بوضع القراءة فقط.
- **Supabase**: مصدر الحالة والتدقيق الحالي، ويستخدم جدول Shadow الموجود وقفل التنفيذ المشترك؛ لا تُضاف أسرار أو جداول جديدة لهذا الدمج.
- **Cloudflare Worker**: يبقى JavaScript/Worker للوحة والفحوص المجدولة ذات القراءة فقط. توحيد Python يخص محرك التداول، لا واجهة الويب أو Worker ذي بيئة تشغيل مختلفة.

## السجلات والتخزين

لا يستخدم APEX حالياً FileHandler ولا ينشئ ملف سجلات محلياً؛ Loguru يرسل المخرجات إلى stdout الذي يعرضه Botkeep. لذلك لا حاجة لإضافة RotatingFileHandler أو نسخ سجلات إلى Supabase. تبقى نبضات التشغيل محفوظة في Supabase، فيما خُفضت رسائل نجاح heartbeat/status إلى DEBUG حتى لا يغرق console. لقطة Botkeep وقت المراجعة كانت 256.9 MB من أصل 2,048 MB، أي إن القرص لم يكن ممتلئاً.

## تطبيق آمن

التغييرات على فرع وطلب مراجعة؛ لا يُعاد تشغيل Botkeep ولا تُرفع إعدادات إلى Cloudflare ولا تُطبق هجرة Supabase تلقائياً. بعد مراجعة ودمج الكود يمكن مزامنة ملفات Botkeep ثم إعادة تشغيله في نافذة مناسبة، مع إبقاء Testnet والتحقق من تجديد القفل وحالة الخدمة قبل أي تشغيل تداول مستمر.
